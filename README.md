# 闲鱼自动分销 SaaS 系统（一期 V1.0）

根据《自动分销系统（闲鱼版）需求说明书 V1.0》开发的全栈云端 SaaS 系统。

## 技术架构

- **后端**：Node.js 零依赖 HTTP 服务（`server.js`），REST API + JSON 持久化（`data/db.json`）
- **前端**：原生 SPA（`public/`），无框架，自动轮询实时刷新
- **平台对接**：内置「闲管家开放平台模拟网关」，签名/接口结构与真实开放平台对齐，替换 `xgj` 对象中的实现即可切正式环境（需企业资质 AppKey/Secret）

## 模块覆盖（对应 PRD 八大模块）

| 模块 | 能力 |
|---|---|
| M1 店铺管理 | 闲管家五步授权绑定向导、多店绑定、解绑、授权状态检测（90 天有效期）、店铺信息同步 |
| M2 商品铺货 | 货源库（1688 模拟）、搜索筛选、单件/批量一键铺货、异步任务队列、成功/失败/铺货中/缺货四态管理 |
| M2 铺货规则 | 加价率、运费加价、上架方式（直接上架/草稿箱）、按店铺独立设置 |
| M3 商品关联 | 闲鱼商品 ↔ 货源手动关联/解除、未关联提醒、预估单件利润 |
| M4 订单管理 | 实时自动回流 + 手动批量回流（近3天）、8 种状态分类、未关联货源订单、订单详情、生成采购单、取消 |
| M5 采购管理 | 采购单列表、单笔/批量付款、合单支付（同供应商同地址校验）、付款记录、亏损单过滤、自动备注、采购价策略 |
| M6 发货管理 | 发货时机设置（3 种模式）、物流自动回传闲鱼、发货状态跟踪、手动刷新物流 |
| M7 售后管理 | 售后自动同步供应商、售后单列表、手动发起、退款进度跟踪 |
| M8 数据统计 | 销售额/采购额/利润总览、趋势图、分店数据、时间筛选、待采购预估利润 |

## 内置模拟引擎

服务每 4 秒推进一次业务引擎：铺货任务异步执行（含违规词/类目/图片等真实失败原因）、订单自动回流、付款后供应商发货 → 物流回传 → 买家收货闭环、售后自动产生与退款推进、授权过期随机提醒。

## 启动

```bash
node server.js
# 默认端口 3788，可用 PORT 环境变量覆盖
```

## 二期预留（V1.1 规划）

数据模型已按「货源双轨制」设计：`goods.source` 字段支持 `1688` / `platform`（平台自有商品池），铺货与采购流程可无缝扩展。
